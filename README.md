# Nova AI (Kotlin, minSdk 26)

## Termux build
1. termux-setup-storage
2. unzip NovaAI.zip && cd NovaAI
3. bash build.sh        (APK -> app/build/outputs/apk/debug/app-debug.apk and /sdcard/Download/NovaAI.apk)

Requires Android SDK (platform 34 + build-tools 34.0.0) at $ANDROID_HOME (default ~/android-sdk).

## First run
Settings -> paste Gemini API key (aistudio.google.com) -> Save.
Settings -> Enable screen control -> turn on "Nova AI".
Commands: open <app> | play <song> | tap X Y | click <text> | swipe up | go back | go home
